# Diseno aprobado: demo de seguridad IaC

El usuario aprobo Terraform y Dockerfile como dos tipos de IaC, un workflow
Checkov, politica YAML y guia de evidencias. No hay despliegue ni secretos.
Se entrega primero una linea base insegura; la remediacion y evidencias de
GitHub son fases posteriores. Ansible agregaria instalacion y reglas sin
ser necesario para el minimo; se eligio el demo de dos tipos.
El informe es una plantilla hasta obtener evidencias reales.
